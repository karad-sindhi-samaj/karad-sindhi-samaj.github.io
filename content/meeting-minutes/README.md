# Meeting minutes archive

No meeting minutes have been published yet.

To add a record, create a Markdown file in this directory (for example, `2026-11-18-community-meeting.md`) and include:

- Meeting date and type
- Attendees or an appropriate attendance summary
- Agenda items
- Decisions and actions, including owners and due dates where agreed
- Approval/publication status

Publish only minutes reviewed through the Samaj's agreed process. Remove or anonymize personal or sensitive information that should not be public.
