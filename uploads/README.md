# Uploads

Upload community-provided images and other approved assets to this directory. Keep filenames simple, for example `annual-gathering-2026.jpg`.

The website currently displays no photos. To show an uploaded image, add an `<img>` element in `index.html` with a relative path such as `uploads/annual-gathering-2026.jpg`.

Before uploading or publishing photos, confirm that they are approved for public sharing and that the people shown have given permission. Take extra care with photos of children.
